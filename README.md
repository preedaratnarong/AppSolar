# NEXORA Solar Planner

WebApp สำหรับคำนวณและสำรวจการติดตั้งโซลาร์เซลล์ รองรับ Desktop, Tablet และ Mobile

## วิธีเปิดใช้งาน

### Windows

ดับเบิลคลิก `START_NEXORA.bat` แล้วเปิด `http://localhost:8080`

### Terminal

1. เปิด Terminal ในโฟลเดอร์โปรเจกต์
2. รัน `python -m http.server 8080`
3. เปิด `http://localhost:8080`

การใช้กล้องบนมือถือจำเป็นต้องเปิดผ่าน HTTPS หรือ localhost หากนำขึ้น GitHub Pages, Cloudflare Pages หรือโฮสติ้ง HTTPS จะสามารถขอสิทธิ์กล้อง, GPS และเข็มทิศได้

## ฟังก์ชันหลัก

- คำนวณจำนวนแผง ขนาดแบตเตอรี่ และอินเวอร์เตอร์
- แนะนำทิศและมุมเอียงตามละติจูด
- Sun Path Camera พร้อม AR overlay, GPS, เข็มทิศ และจำลองฤดูกาล
- บันทึกหลายโครงการในอุปกรณ์
- ฐานข้อมูลอุปกรณ์ ปรับค่ากำลังแผง/แบตเตอรี่/อินเวอร์เตอร์ได้
- ส่งออกรายงาน CSV และพิมพ์เป็น PDF
- PWA ติดตั้งบนหน้าจอมือถือได้
- เพิ่ม/เปลี่ยนภาพพื้นหลังจากเมนู ตั้งค่า พร้อมปรับความเข้ม ความเบลอ ตำแหน่ง และรูปแบบการวาง

## การเพิ่มภาพพื้นหลัง

เข้าเมนู `ตั้งค่า` → `ภาพพื้นหลังแพลตฟอร์ม` → เลือกภาพ → ปรับค่า → กด `บันทึกภาพพื้นหลัง`

ภาพพื้นหลังจะเก็บเฉพาะในเบราว์เซอร์ของเครื่องนั้น ไม่ถูกส่งขึ้นเซิร์ฟเวอร์ และจะไม่ปนกับข้อมูลโครงการเครื่องอื่น

## การทดสอบบน GitHub Pages

อัปโหลดไฟล์ภายใน ZIP ไปยัง repository แล้วเปิดใช้งาน GitHub Pages จาก branch ที่เก็บ `index.html` ไว้ที่ root จากนั้นเปิดลิงก์ด้วย HTTPS เพื่อให้กล้อง, GPS และเข็มทิศทำงานได้

หากเปิดแล้วยังเห็นหน้าตาเวอร์ชันเก่า ให้รีเฟรชแบบล้างแคชหนึ่งครั้ง หรือเปิดใน Private/Incognito เพื่อให้ Service Worker รุ่นใหม่โหลดไฟล์ล่าสุด

> ผลคำนวณเป็นการออกแบบเบื้องต้น ต้องตรวจสอบโครงสร้าง ระบบไฟฟ้า เงาบัง และข้อกำหนดของการไฟฟ้าโดยผู้เชี่ยวชาญก่อนติดตั้งจริง
